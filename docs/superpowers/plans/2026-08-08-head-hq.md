# Head HQ Page (`/head-hq`) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the Head agent a dedicated console. Frontend-only — no backend changes. Three sections:
1. **Plan console** — type a goal, dispatch the `head` agent, and see the resulting plan (`seed_query`, `tools`, `skill_gaps`, `rationale`) pulled from the head agent-run's `output_json`.
2. **Dispatch console** — quick-fire a head run (goal input) with flash feedback.
3. **History** — recent pipeline runs (all agents) and recent head agent-runs, auto-refreshing.

**Architecture:** Reuses existing endpoints as data sources (no new backend):
- `POST /api/agents/head/dispatch` (async; returns `PipelineRun`) — via `apiSend`.
- `GET /api/pipeline-runs/{id}` — poll a just-dispatched run to completion.
- `GET /api/agent-runs?agent_name=head&limit=20` — head agent-run history (plan lives in `output_json`).
- `GET /api/pipeline-runs?limit=20` — recent runs across agents.

The plan console polls the pipeline run every 2s until it reaches `success`/`failed`, then fetches the matching head agent-run to render `output_json` as a plan card. `refetchInterval: 10000` refreshes both history tables.

**Tech Stack:** Existing — React + TypeScript, @tanstack/react-query, vitest + @testing-library/react, flat API helpers in `web/src/api/*.ts`.

## Global Constraints

```ts
export function fetchAgentRuns(
  agentName?: string,
  pipelineRunId?: string,
  limit = 20,
): Promise<AgentRun[]> {
  const params = new URLSearchParams();
  if (agentName) params.set("agent_name", agentName);
  if (pipelineRunId) params.set("pipeline_run_id", pipelineRunId);
  params.set("limit", String(limit));
  return apiGet<AgentRun[]>(`/api/agent-runs?${params.toString()}`);
}

export function fetchPipelineRun(id: string): Promise<PipelineRun> {
  return apiGet<PipelineRun>(`/api/pipeline-runs/${id}`);
}

export function fetchPipelineRuns(limit = 50): Promise<PipelineRun[]> {
  return apiGet<PipelineRun[]>(`/api/pipeline-runs?limit=${limit}`);
}
```
